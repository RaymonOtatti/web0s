# Web0S

Portfolio web para mostrar La Guardia Barrio Abierto, Raymon Otatti Design & Co., Franie Smith y Sáenz Valiente & Asociados.

## Vista local

Desde esta carpeta:

```powershell
python -m http.server 4325 --directory dist
```

Abrir `http://127.0.0.1:4325/`.

El sitio está hecho en HTML, CSS y JavaScript sin paso de build. Las capturas de los cuatro proyectos están en `dist/images/`.

La Guardia y Raymon Otatti tienen enlace al sitio público. Franie Smith y SVYA muestran una vista ampliada hasta contar con las URL de estas versiones.
